# GUI 行为与配置

此文档依据当前 Rust 和静态前端整理，不是原 WPF 迁移规格。界面文案以中文为主；产品名和主窗口标题保持当前 `Google Chrome` 配置。

## 主窗口

Tauri 默认主窗口为 800×550。`ui/index.html`、`style.css` 定义布局，`app.js` 负责 IPC 和状态：

- 工具栏：开始、停止、颜色设置、抛竿键输入、拟人化开关、周期宏设置和定时动作。
- 预览区：初始图片，运行后接收后端 PNG；匹配像素染为当前模式的红/蓝色，浮漂位置叠加准星，未找到时仍在位图原点绘制准星。
- 曲线卡：默认折叠，点击“显示图表”展开；显示 BobberMove 幅度，折叠时不加数据点。零线为蓝色，参考线跟随当前会话实际阈值，空闲时显示下次启动值；时间窗口为过去 8 秒至未来 1 秒，纵轴随阈值扩展。
- 日志卡：默认折叠，点击“显示日志”展开；新消息插到顶部，包含前端接收时间、递增序号和消息，最多保留最近 500 条。
- 拾取动画：Loot 时显示拾取文字和飞鱼，Cast 时停止并隐藏动画、清空曲线；Cast 后首帧重取预览背景色。

开始后按钮切换为可停止状态，启动期间也能停止；Stopping 阶段禁止重复点击，后端退出后恢复。启动失败重新查询状态恢复按钮。开始约十分钟后两张卡自动翻到背面，停止会取消该计时器并隐藏拾取动画。飞鱼由 `anim.js` 管理，曲线由 `chart.js` 绘制。

开始时绑定目标窗口，最多等待 60 秒让用户切回游戏后才发送空格，每 100ms 检查一次前台状态。工具栏显示“等待魔兽世界进入前台”和剩余秒数，每秒更新，等待期间可点击停止取消；检测通过后显示“正在启动钓鱼”，进入运行后隐藏提示。超时取消本次启动并显示错误。前台校验只要求前台窗口属于绑定的游戏进程，不查询控件键盘焦点，也不强制激活游戏。前台切到其他进程、目标关闭、鼠标位置变化或输入失败时停止本次会话，并在底部显示错误。Loot 动画仅在右键操作执行成功后触发，不表示物品获取成功。关闭主窗口先取消会话并等待桥接线程退出；十秒未清理完时保留窗口，提示稍后重试。

## 颜色配置窗口

设置命令使用异步 Tauri handler 创建窗口，避免 Windows 上同步创建 WebView 的加载问题。每次打开创建独立 `colour-*` 窗口，置顶并请求聚焦；窗口实例共享后端分类器和搜索区域，多窗口前端控件之间不主动同步显示。

`colour.js` 使用原始离屏 Canvas 取色，避免把高亮像素当成原始颜色。截图由用户点击后获取，不自动连续刷新。颜色滑条拖动时更新说明，结束后原子保存并渲染高亮；颜色立方图用于显示当前匹配条件。

点击截图可按采样颜色调整分类参数，拖动超过 5 像素则视为框选区域。区域坐标转换为原始位图坐标，不是预览缩放后的 CSS 坐标。清除区域后恢复全图搜索。

## 设置生效范围

| 设置 | 默认值 | 生效时间 | 跨应用重启保存 |
| --- | --- | --- | --- |
| 抛竿键 | D4 | 运行中更新共享键值，后续抛竿读取 | `settings.json` |
| 周期宏键 1、2 | D5、D6 | 保存后下次启动；启动及每个周期依次执行，空键跳过 | `settings.json` |
| 周期宏间隔 | 10 分钟 | 保存后下次启动；1..10080 整数分钟，拟人化开启时附加 0..=90s | `settings.json` |
| 颜色模式 | Red | 后续识别帧 | `settings.json` |
| 两个颜色乘数 | 0.5、2，可手动调整 | 拖动结束保存后的识别帧 | `settings.json` |
| 拾取延迟 | 2000ms | 拖动结束保存后下一次拾取读取 | `settings.json` |
| 下沉阈值 | 7px | 下次启动机器人 | `settings.json` |
| 搜索区域 | 无 | 后续帧读取并重新确认；约束所有候选 | `settings.json` |
| 拟人化开关 | 开 | 下次启动机器人（参数见 `fishing_core::humanize` 默认值） | `settings.json` |

按键持久化使用 Win32 VK/ConsoleKey 整数；抛竿键界面仅对字母及 D0..D9 显示简短名称，其他合法键显示 `?`。周期宏键显示完整名称（例如 D5、F1），点击后按键修改，按 Tab 可离开输入框；只绑定单个键，不支持组合快捷键。每个宏键可清空，两个都清空即可禁用宏键发送；基础周期独立于拟人化开关。宏设置统一保存，加载或保存期间禁用编辑；保存失败保留草稿并显示错误，成功提示下次启动生效。配置固定目录、首次导入规则见 README。

拟人化开关同时控制核心节奏和鼠标曲线/落点偏移，下次启动生效；读取和保存期间禁用，保存失败回滚到已保存状态。

Tauri 自定义命令集中在 `src/main.rs` 的 `generate_handler!` 注册表，前端通过 `window.__TAURI__.core.invoke` 调用。原生事件权限适用于 `main` 和 `colour-*`；当前配置启用全局 Tauri API，CSP 为 null。这些是现有实现的描述，后续权限收紧需要同时回归两个窗口的 IPC 和资源加载。

## 客户区、恢复与诊断

截图和机器人使用同一绑定窗口的客户区。框选同时提交原始截图尺寸，窗口已缩放时要求重新截图；区域随下次启动的客户区尺寸按比例映射。会话中移动或缩放窗口会停止，需重新开始。旧主屏区域升级后清除，GDI 捕获仍需游戏画面可见。

工具栏显示当前阶段和定时剩余分钟数。展开“设置恢复与诊断”可查看目标、捕获计数/错误/耗时、连续未识别帧及最近错误，每秒刷新，停止后保留。

面板提供导出设置、本机 JSON 导入、恢复默认值和诊断导出。导入/恢复只允许空闲时执行，先备份原文件；备份失败不覆盖。损坏配置进入恢复模式，禁止启动和普通写入。恢复成功广播 `settings-restored`，两个窗口重载设置，颜色窗口清除旧截图。文件日志轮转保存在 Tauri `app_log_dir`；诊断包含当前日志末尾最多 128KiB，不含截图。
